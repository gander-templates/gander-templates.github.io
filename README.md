# gander-templates.github.io

Landing page for the [gander-templates](https://github.com/gander-templates) organization, published at <https://gander-templates.github.io/>.

Shared project and repository templates by gander.

## Development

The site is built by GitHub Pages with [Jekyll](https://jekyllrb.com/). Projects are listed in `_data/projects.yml`; add an entry there to show a new project on the page. Only public repositories belong on the page.

```sh
bundle install
bundle exec jekyll serve
```
